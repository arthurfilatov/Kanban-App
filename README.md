# 📋 Fullstack Kanban Board (React 19 + FastAPI)

Приложение для управления задачами.

## 🚀 Технологический стек

### Frontend

- **React 19**
- **Vite 7**
- **Tailwind CSS 4**
- **dnd-kit**
- **TypeScript**

### Backend

- **FastAPI (Python 3.14)**
- **Pydantic**
- **Docker & Docker Compose**

---

## ✨ Ключевые фичи

### 🛡 Надежный UI (Optimistic Updates)

Реализован механизм «оптимистичных обновлений». Изменения в интерфейсе (перетаскивание, редактирование) происходят мгновенно. В случае ошибки сервера срабатывает **Rollback** — состояние автоматически откатывается к последнему стабильному, предотвращая рассинхронизацию.

### ⚡ Производительность

- Использование `useMemo` для фильтрации и поиска задач.
- Cенсоры (Pointer & Keyboard) с порогом активации (`distance`), что исключает ложные срабатывания Drag-and-Drop при обычном клике.

### 🐳 Инфраструктура

Проект полностью контейнеризирован. Это гарантирует, что приложение запустится без необходимости ручной настройки окружения Python или Node.js.

## 📦 Быстрый запуск (через Docker)

Это рекомендуемый способ запуска. Вам понадобится только установленный Docker Desktop.

1. Клонируйте репозиторий:

```bash
   git clone https://github.com/arthurfilatov/Kanban-App.git
   cd Kanban-App

```

2. В корне проекта выполните:

```bash
docker-compose up --build

```

3. Откройте приложение:

Интерфейс (React): http://localhost:5173

Документация API (Swagger): http://localhost:8000/docs
