# Fullstack Kanban Board

Современное приложение для управления задачами с интерфейсом Drag-and-Drop и быстрым бэкендом на FastAPI.

## 🚀 Технологический стек

- **Frontend:** React 19, TypeScript, Tailwind CSS, dnd-kit.
- **Backend:** FastAPI (Python 3.14), Pydantic.
- **Инструменты:** Vite, Lucide Icons.

## ✨ Основные возможности

### 1. Надежный UI (Optimistic Updates & Rollback)

В приложении реализовано "оптимистичное" обновление интерфейса. Когда вы перемещаете задачу или редактируете её, изменения отображаются мгновенно. В случае сбоя сети или ошибки сервера, состояние автоматически откатывается до последнего стабильного (Rollback), что гарантирует сохранность данных.

### 2. Производительность

Использование хука `useMemo` для фильтрации задач позволяет приложению работать плавно даже при большом количестве данных и активном использовании поиска.

### 3. Drag-and-Drop

Настроены специализированные сенсоры (Pointer & Keyboard) с порогом активации (`distance`), что исключает случайные перемещения при обычном клике по задаче.

## 📦 Как запустить проект

Для запуска всей системы (Frontend + Backend) одной командой понадобится только установленный Docker:

```bash
docker-compose up --build
```
