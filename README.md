# 📋 Fullstack Kanban Board (React 19 + FastAPI)

Приложение для управления задачами, созданное на актуальном стеке.

## 🚀 Технологический стек

### Frontend

- **React 19** (использование новейших возможностей рендеринга)
- **Vite 7** (молниеносная сборка)
- **Tailwind CSS 4** (современная стилизация)
- **dnd-kit** (гибкий и доступный Drag-and-Drop)
- **TypeScript** (строгая типизация)

### Backend

- **FastAPI (Python 3.14)** (высокопроизводительный асинхронный API)
- **Pydantic** (валидация данных)
- **Docker & Docker Compose** (полная изоляция среды разработки)

---

## ✨ Ключевые фичи

### 🛡 Надежный UI (Optimistic Updates)

Реализован механизм «оптимистичных обновлений». Изменения в интерфейсе (перетаскивание, редактирование) происходят мгновенно. В случае ошибки сервера срабатывает **Rollback** — состояние автоматически откатывается к последнему стабильному, предотвращая рассинхронизацию.

### ⚡ Производительность

- Использование `useMemo` для фильтрации и поиска задач.
- Кастомные сенсоры (Pointer & Keyboard) с порогом активации (`distance`), что исключает ложные срабатывания Drag-and-Drop при обычном клике.

### 🐳 Инфраструктура

Проект полностью контейнеризирован. Это гарантирует, что приложение запустится одинаково на любой операционной системе без необходимости ручной настройки окружения Python или Node.js.

## 📦 Быстрый запуск (через Docker)

Это рекомендуемый способ запуска. Вам понадобится только установленный Docker Desktop.

1. Клонируйте репозиторий.
2. В корне проекта выполните:

```bash
docker-compose up --build


```
